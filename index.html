Vocem Overlay — the Vulkan layer for Flatpak games

A Flatpak repository holding one extension. Signed.

Vocem Overlay draws your Discord voice channel inside the game. It is installed on the host; this extension is the part that reaches games installed as Flatpaks, which the host installation cannot.

Install

flatpak install --user https://ales-drnz.github.io/vocem-overlay/vocem-overlay-layer.flatpakref

That is the 25.08 branch, for games on the freedesktop 25.08, GNOME 49 and 50, and KDE 6.10 and 6.11 runtimes. Games on freedesktop 26.08 or GNOME 51 -- Steam from Flathub among them -- mount the 26.08 branch instead:

flatpak install --user vocem-overlay org.freedesktop.Platform.VulkanLayer.VocemOverlay//26.08

flatpak update keeps both current afterwards. It needs vocemd running on the host, which the main installation provides; vocem-why --system there lists the runtimes installed and whether each one's branch is.

OpenGL games

Flatpak has no mechanism for a preload, so an OpenGL game needs one more command:

flatpak override --user --env=LD_PRELOAD=libvocem_gl_shim.so --env=LD_LIBRARY_PATH=/usr/lib/extensions/vulkan/VocemOverlay/lib/x86_64-linux-gnu:/usr/lib/extensions/vulkan/VocemOverlay/lib/i386-linux-gnu

Vulkan games need nothing.
